## 🇪🇸 ESPAÑOL

### Estructura del Repositorio

Para mantener el proyecto organizado, los archivos se encuentran divididos en las siguientes carpetas:

- **`code/`**: Contiene las páginas principales del sitio en HTML (`carros.html`, `modelos.html`, `servicios.html`, `promociones.html` y `Comprar.html`).
- **`code/src/`**: Contiene los recursos multimedia utilizados por el sitio, incluyendo imágenes, logotipos y videos de fondo.
- **`code/src/demo/`**: Contiene las capturas de pantalla para la vista previa del proyecto.

### Instrucciones de Ejecución Local

Para visualizar AUREX en tu computadora:

1. Descarga o clona este repositorio.
2. Abre la carpeta `code/`.
3. Ejecuta el archivo **`carros.html`** en tu navegador web de preferencia.

No es necesario mover, reorganizar ni modificar ningún archivo. El proyecto utiliza sus rutas actuales para acceder a los recursos multimedia.

## 🇬🇧 ENGLISH

### Repository Structure

To keep the project organized, files are divided into the following directories:

- **`code/`**: Contains the main HTML pages (`carros.html`, `modelos.html`, `servicios.html`, `promociones.html`, and `Comprar.html`).
- **`code/src/`**: Contains the multimedia assets used throughout the website, including images, logos, and background videos.
- **`code/src/demo/`**: Contains screenshots for the project preview.

### Local Execution Instructions

To view AUREX on your computer:

1. Download or clone this repository.
2. Open the `code/` directory.
3. Run **`carros.html`** in your preferred web browser.

There is no need to move, reorganize, or modify any files. The project uses its current paths to access all multimedia resources.
