#  AUREX - Proyecto Web de Superdeportivos / Supercars Web Project

Sitio web multimarcas de alta gama desarrollado para la gestión y exhibición de superdeportivos, modelos exclusivos, servicios y apartado de compras[cite: 1].

---

## 🇪🇸 ESPAÑOL

###  Estructura del Repositorio
Para mantener el proyecto organizado en GitHub, los archivos se encuentran divididos en las siguientes carpetas:
- **`code/`**: Contiene las páginas principales en código HTML (`carros.html`, `modelos.html`, `servicios.html`, `promociones.html`, `Comprar.html`)[cite: 1].
- **`src/`**: Contiene los recursos multimedia (imágenes, logotipos y videos de fondo)[cite: 1].

###  Instrucciones de Ejecución Local
Para visualizar el sitio web en tu computadora y asegurar que todas las imágenes y videos carguen correctamente:

1. Descarga o clona este repositorio en tu equipo.
2. Extrae y **mueve todos los archivos** que están dentro de las carpetas `code/` y `src/` para que **queden juntos en un mismo directorio raíz**.
3. Abre el archivo **`carros.html`** en tu navegador web de preferencia para iniciar el recorrido por el sitio.

## 🇬🇧 ENGLISH

###  Repository Structure
To keep the project organized on GitHub, files are separated into the following directories:
- **`code/`**: Contains the main HTML pages (`carros.html`, `modelos.html`, `servicios.html`, `promociones.html`, `Comprar.html`)[cite: 1].
- **`src/`**: Contains multimedia assets (images, logos, and background videos)[cite: 1].

###  Local Execution Instructions
To properly display the website on your local machine and ensure all media files load seamlessly:

1. Download or clone this repository to your computer.
2. Extract and **move all files** inside `code/` and `src/` so they **reside together in a single root directory**.
3. Open **`carros.html`** in your preferred web browser to view the site.
